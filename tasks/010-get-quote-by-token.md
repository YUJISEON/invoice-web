## 확인된 사항

- **개발 모드 전용 노출**: dev 서버에서는 React가 `await`한 노션 API 원본 응답(페이지 객체, 속성명, `database_id`, `data_source_id`, 사용자 ID)이 디버그 정보로 응답에 포함된다. **production 빌드에서는 포함되지 않음을 확인**했다. 개발 중에는 이 응답을 외부에 공유하지 않는다
- **개발 서버 로그**: Next 개발 서버의 요청 로그(`GET /quote/<토큰> 200`)에 토큰이 찍힌다. 앱 코드가 남기는 로그에는 토큰이 없다. production(`next start`)의 서버 로그에는 요청 로그가 찍히지 않았다
- production 오류 응답 payload에 Next의 `digest`(불투명 해시)가 포함되며 화면에는 표시되지 않는다
- Next 프레임워크 속성 `"unauthorized":"$undefined"`는 오류 정보가 아니다
