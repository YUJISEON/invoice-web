## 응답 시간 (프로덕션, 한국 → Vercel 함수 `iad1`)

| 요청                            | 측정                      |
| ------------------------------- | ------------------------- |
| 정상 견적서(품목 2건, 호출 2회) | 0.95초, 0.74초(첫 측정)   |
| 없는 토큰(호출 1회) 5회         | 0.47~0.52초 (로컬 0.30초) |
| 형식 불량(호출 없음) 3회        | 0.28~0.31초               |

형식 불량 응답이 0.3초인 점으로 보아 한국↔미국 동부 왕복 지연이 약 0.25초이고, 정상 견적서는 약 0.75~0.95초다. 체감상 충분해 기본 지역(`iad1`)을 유지한다. 노션 서버 위치를 확인하지 못해 `icn1`이 더 빠르다고 단정할 수 없으며, 필요 시 `vercel.json`의 `regions`로 바꿔 같은 방법으로 비교한다.
