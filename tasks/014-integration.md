# Task 014: 프로덕션 모드 통합 검증

관련 기능: F001, F002, F003, F004, F010

`npm run build` + `npm start`(production)에서 실제 노션 데이터로 전체 사용자 여정과 엣지 케이스를 검증했다. 노션에 임시 견적서 8건과 품목 34건을 추가해 확인한 뒤 모두 삭제했고, 원래 데이터(`INV-2026-001`, 품목 3건)는 변경하지 않았다.

## 테스트 데이터

| ID   | 임시 견적서                 | 내용                                                               |
| ---- | --------------------------- | ------------------------------------------------------------------ |
| T-01 | `INV-2026-001`(원래 데이터) | 품목 3건, 비고·담당자 없음, 발행일 2026-10-01, 유효기간 2026-10-10 |
| T-02 | `INV-2026-001`              | 유효기간이 지난 견적서(위와 동일)                                  |
| T-03 | P                           | 유효기간 = 오늘(2026-11-01, 한국 시간), 품목 1건                   |
| T-04 | Q                           | 발행일·유효기간·담당자명·비고 모두 비어 있음, 품목 1건             |

## 확인하지 못한 것 / 한계

- **다중 페이지 PDF의 시각 확인**: PDF를 이미지로 렌더하는 도구가 없어 2페이지에서 표 헤더가 실제로 반복되고 행이 정확히 어디서 나뉘는지는 눈으로 확인하지 못했다. CSS 속성(`table-header-group`, `break-inside: avoid`)과 페이지 수로 대체했다. 실제 브라우저 인쇄는 Task 018(실기기)에서 확인한다
- **Task 009 잔여 항목**: 노션 `토큰` 속성을 select 등 다른 타입으로 바꿨을 때의 오류 화면. 노션 스키마를 바꿔야 해서 시도하지 않았다. 매퍼 단위(`NotionMappingError`)와 오류 변환(`toQuoteUnavailableError`)은 Task 009·012에서 확인했다
- 응답 지연(타임아웃)에서 일반 오류 화면까지의 대기 시간은 Task 016에서 확인한다
